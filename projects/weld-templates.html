Project 02 | Manufacturing Tooling & Process Improvement

Angle Ring Stitch-Weld Templates

Reusable layout templates developed to establish consistent weld quantity and stitch spacing for angle-ring attachment to round ductwork.

Project Overview

Designed reusable layout templates for attaching angle rings to round ductwork. Each template corresponds to applicable duct and angle-ring sizes and provides a repeatable guide for weld quantity and stitch spacing.

Instead of laying out every weld location individually with a tape measure, fabricators can use the template to transfer the required stitch locations directly to the assembly.

Impact

Faster layout, more uniform stitch spacing, improved repeatability, and reduced potential for measurement error.

Problem Addressed

  • Repeated manual layout of weld locations
  • Time required to measure stitch spacing for recurring duct sizes
  • Potential variation between individual fabrication setups
  • Need for a repeatable method that could be used directly on the shop floor

Design Response

  • Reusable size-based template system
  • Predefined stitch locations and spacing
  • Quick fit-up to the applicable duct and angle ring
  • Consistent layout method for repeat assemblies

Weld-Layout Template

Reusable layout template used to establish consistent weld quantity and stitch spacing for angle-ring attachment.

Shop-Floor Use

Step 01 Select Template

Use the template corresponding to the applicable duct and angle-ring size.

Step 02 Establish Weld Locations

Use the predefined template locations to transfer the stitch-weld layout to the assembly.

Step 03 Repeat Consistently

Reuse the same layout method on recurring assemblies rather than measuring each weld pattern individually.

Manufacturing Focus

The template converts a recurring manual measurement task into a reusable physical layout method. The design emphasizes practical shop-floor use, repeatability, and straightforward application by fabricators.

Design Intent

The objective was not to add complexity to the fabrication process, but to simplify a repetitive layout operation by building the required weld pattern into a reusable tool.

Portfolio Significance

  • Identified a repetitive manufacturing task suitable for tooling
  • Developed a reusable physical layout system
  • Improved consistency across recurring fabrication work
  • Reduced reliance on repeated manual measurement
  • Designed around direct shop-floor use
  • Demonstrates practical manufacturing process improvement
