Project 02 | Manufacturing Tooling

Angle Ring Stitch-Weld Templates

Reusable fabrication templates developed to establish consistent stitch-weld locations and reduce repeated manual layout during angle-ring attachment.

Project Overview

Designed reusable layout templates for attaching angle rings to round ductwork.

Each template corresponds to the applicable duct and angle-ring size and provides predefined locations for weld quantity and stitch spacing.

Fabricators can transfer the required locations directly from the template instead of separately laying out each stitch location with a tape measure.

Impact

Faster layout, more consistent stitch spacing, improved repeatability, and reduced opportunity for manual measurement error.

Problem Addressed

  • Weld locations required repeated manual layout
  • Layout depended on measuring around each duct and angle ring
  • Repetitive measurement created opportunities for variation
  • Similar assemblies required the same layout process repeatedly

Design Response

  • Reusable, size-specific template system
  • Predefined stitch-weld locations and spacing
  • Quick fit-up to the corresponding duct and angle-ring size
  • Simple visual layout method for repeat fabrication

Shop-Floor Workflow

The tooling converts a repeated measuring task into a simple, repeatable transfer process.

STEP 01
Match Template Select the template corresponding to the duct and angle-ring size.
STEP 02
Transfer Layout Position the template and transfer the predefined stitch locations to the assembly.
STEP 03
Repeat Consistently Use the same layout method across repeat assemblies of the applicable size.

Engineering Considerations

  • Applicable duct and angle-ring sizes
  • Required weld quantity
  • Stitch spacing around the circumference
  • Template fit and positioning
  • Ease of identification and repeated use

Production Value

  • Reduced repetitive measuring
  • Consistent weld-location layout
  • Improved repeatability between assemblies
  • Simple tooling requiring minimal setup
  • Reusable method for recurring fabrication work

Weld-Layout Template

Reusable circular layout template with predefined holes and markings for establishing weld quantity and stitch locations across multiple duct and angle-ring sizes.

Portfolio Significance
