Project 04 | Material Handling & Fixture Design

Forklift-Mounted Large-Duct Support Saddle

Modular material-handling fixture using a common welded base and interchangeable saddle assemblies to support multiple large-duct diameter ranges.

Project Overview

Designed a forklift-mounted saddle to support large-diameter ductwork during angle-ring installation.

Rather than creating a separate complete fixture for each duct size, the design uses a common welded base frame with removable upper roller-weldment saddle assemblies.

Three interchangeable upper assemblies provide different support radii so the fixture can be configured for different duct-size ranges while retaining the same base and forklift interface.

Impact

One reusable base supports multiple duct-diameter ranges, reducing the need for separate complete fixtures while providing a stable support method for duct handling and fit-up.

Design Response

  • Rigid forklift-compatible welded base frame
  • Three removable roller-weldment saddle assemblies
  • Different saddle radius for each applicable duct-size range
  • Curved, padded contact surfaces for supporting the duct

Modular Configuration

  • Common lower structure remains mounted to the forklift
  • Upper saddle assembly is swapped as duct size changes
  • Forklift interface is reused across configurations
  • Modular construction avoids duplicating the entire fixture

Modular Design Concept

The fixture separates the universal material-handling interface from the duct-specific support geometry.

Engineering Considerations

  • Duct diameter and saddle contact radius
  • Fixture stability during positioning
  • Forklift compatibility and placement
  • Duct-contact surface protection
  • Ease of changing upper saddle assemblies

Production Value

  • Reusable fixture architecture
  • Adaptability across multiple duct sizes
  • Reduced reliance on improvised blocking
  • Controlled support during angle-ring fit-up
  • Simple configuration changes for shop-floor use
